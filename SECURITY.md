# Security Policy

## Supported versions

Create: Pocket Dynamo is in early development. Only the latest release (currently the 0.1.x line) receives fixes.

| Version | Supported |
|---|---|
| 0.1.x | Yes |
| Anything older | No |

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately through GitHub: open the [Security tab](https://github.com/ShadowPJ/create_pocketdynamo/security/advisories/new)
and choose **Report a vulnerability**. Include:

- what the problem is and which version is affected,
- steps to reproduce it (a world save or a short description is enough),
- the impact you expect (crash, item duplication, griefing, code execution, ...).

You can expect an answer within a few days. Once the problem is confirmed and fixed, it is disclosed in the release
notes, and you are credited if you want to be.

## What counts

In scope: anything that lets a player or another mod crash a server, corrupt a world, bypass permissions, or run code
because of this addon. Balance exploits and duplication glitches are welcome as normal issues.

## Secrets

If you find a token, key or password in this repository or its history, report it the same way. Do not use it.
