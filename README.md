# Create: Pocket Dynamo

A portable, battery-powered motor for [Create](https://github.com/Creators-of-Create/Create). Charge it, pick it up with
a wrench, carry it anywhere, and keep it topped up with solar panels.

> **Status: early development (0.1.0).** All textures and models are placeholders, and block ids may still change
> before a 1.0 release.

## Requirements

| | |
|---|---|
| Minecraft | 1.21.1 |
| Loader | NeoForge 21.1.x (built against 21.1.219) |
| Create | 6.0.11 or newer in the 6.0 line |
| Java | 21 |

Optional: JEI or EMI (adds a description page for every item), Ponder (bundled with Create, adds in-game tutorials).

## What it adds

### Portable Motors (copper, brass, diamond)

A kinetic generator with an internal battery. It turns stored Forge Energy (FE) into Rotational Force.

- Speed and direction are selected on the value panel, like Create's Creative Motor, up to the tier's maximum.
- It drains the battery while it spins: a cost per RPM (even with nothing connected) plus a cost proportional to the
  stress its share of the network carries.
- Sneak + Create Wrench picks it up as an item that **keeps its charge and selected speed**. The item shows a charge bar.
- When the battery runs dry it stops, and it starts again by itself once it receives energy.

| Tier | Max RPM | Stress capacity | Battery | Speed cost |
|---|---|---|---|---|
| Copper | 32 | 16,384 SU | 200,000 FE | 0.30 FE/t per RPM |
| Brass | 64 | 49,152 SU | 400,000 FE | 0.25 FE/t per RPM |
| Diamond | 256 | 262,144 SU | 2,000,000 FE | 0.20 FE/t per RPM |

Stress capacity is shown at maximum RPM (SU per RPM x RPM).

### Solar Panels (copper, brass, diamond)

Generate FE from sunlight and push it into adjacent cables, motors and batteries. They need open sky in a dimension
with skylight; night and rain reduce the output.

| Tier | Output at full sun | Buffer |
|---|---|---|
| Copper | 20 FE/t | 2,000 FE |
| Brass | 60 FE/t | 6,000 FE |
| Diamond | 180 FE/t | 18,000 FE |

### Energy Cable

A simple FE cable that connects on its own to other cables and to any block exposing an FE capability. Energy spreads by
local levelling, not by a global network graph. Cables never pull from other blocks: producers push into them.

## Configuration

Server config, one file per world: `serverconfig/create_pocketdynamo-server.toml`. Every number above is configurable
(per tier for motors and panels, plus the rain multiplier and the cable throughput).

## Building

Requires a JDK 21.

```
./gradlew build      # jar in build/libs
./gradlew runData    # regenerates src/generated/resources
./gradlew runClient
```

`dev_recipe_viewer` in `gradle.properties` (`jei`, `emi` or `none`) picks which viewer runs in the dev client. They are
never loaded together.

### Translations

`en_us.json` is generated by `runData`; other languages (currently `es_es`) are hand-written in
`src/main/resources/assets/create_pocketdynamo/lang/`. After changing any text, check that nothing is missing:

```
java tools/LangCheck.java
```

### Ponder scenes

The scene structures are generated, not hand-edited. To change one, edit `tools/PonderStructureGen.java` and run:

```
java tools/PonderStructureGen.java src/main/resources/assets/create_pocketdynamo/ponder
```

`runData` verifies that the schematics load and contain the blocks the scenes rely on.
